## Non-redistributable works
### [Twin Turbo](https://ko-fi.com/s/5b5b175c2a) by [Chained_tan (dedalocious)](https://x.com/chained_tan)

![Twin Turbo asset thumbnail image](./Non%20Redistributables/Twin%20Turbo/thumbnail.png "ツインターボ Twin Turbo")

1. Fix clavicle vertex-bone mismatch with Blender.
1. Export as .FBX format from Blender and name it as  `Twin Turbo.fbx`.
1. Import the .FBX file and the texture into Unity.

### [Mixamo Animations](https://www.mixamo.com/) by [Adobe](https://adobe.com)
1. Upload the .FBX file of [Twin Turbo](#twin-turbo-by-chained_tan-dedalocious).
1. Search and select following animations.

    - <details>
        <summary>Female Basic Locomotion Pack 12 animations</summary>

        - `idle.fbx`
        - `jump.fbx`
        - `left turn.fbx`
        - `left turn (2).fbx`
        - `left strafe.fbx`
        - `left strafe walk.fbx`
        - `right turn.fbx`
        - `right turn (2).fbx`
        - `right strafe.fbx`
        - `right strafe walk.fbx`
        - `running.fbx`
        - `walk.fbx`

    </details>

1. Download the animations with the following options:
    - Format: FBX Binary (.fbx)
    - Pose: No Character
    - Frames per Second: 60
    - Keyframe Reduction: none
1. Import into Unity.
